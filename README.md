# 弦间

弦间是一款轻量的在线吉他六线谱编辑器，面向需要随手记录旋律、整理吉他谱，并在电脑、平板和手机上查看乐谱的使用场景。

项目希望用更直观、更接近纸质乐谱的方式完成简单制谱：点击六线谱填写品位、添加和弦和歌词，也可以加入图片页面作为参考。

当前版本不依赖账号或后端服务，乐谱保存在本地，并可通过 JSON 文件导入、导出和迁移到其他设备。

## 部署

线上环境为静态站点：`npm run build` 产出 `dist/`，由 nginx 托管。

自动构建部署（CI）流程见 [deploy.md](deploy.md)，首次搭建与完整排查手册见 [docs/deploy.md](docs/deploy.md)，发布脚本与 nginx 配置在 `deploy/` 目录。
