## 这是什么

弦间是一款轻量的在线吉他六线谱工具，适合随手记下一段旋律、整理喜欢的吉他谱，然后在电脑、平板或手机上安静地看谱。

它刻意做得接近纸质乐谱：没有复杂的制谱流程，也不要求注册账号——点击六线谱上的弦线填上品位，谱就记下来了。所有谱本保存在浏览器本地，不会上传到任何服务器。

## 能做什么

- **六线谱编辑**：点击弦线即可填品位，支持 `0–6` 品和 `X` 闷音，默认标准调弦 E A D G B E
- **和弦与歌词**：为每个音位添加自定义和弦，支持多行歌词，长歌词会自动收缩排版
- **演奏记号**：琶音、扫弦、延音线、击弦 `H`、勾弦 `P`，可选择弦范围或连接两个音位
- **单节多音**：同一个音位可以竖向叠加多个音级，还原真实按弦
- **选择与复制**：开启选择模式后可框选、多选音符，复制粘贴到任意位置，非相邻音符也能一起复制
- **撤回与重做**：每一步编辑都能撤回，手滑也不怕
- **图片参考页**：填入图片 URL，把参考图片和谱子放在同一本谱里对照查看
- **预览模式**：接近纸质乐谱的阅读视图，适合演奏时查看
- **导入与导出**：支持单个页面 / 单本谱的 JSON 导出，以及全部谱本的 ZIP 批量导入导出，方便备份和换设备
- **本地优先**：乐谱保存在浏览器 IndexedDB，无账号、无后端、无上传

## 快速上手

1. 打开 <http://music.kqhsxt.cn/>
2. 点「新建谱本」，给谱本起个名字
3. 新建六线谱页面，点击弦线填写品位；点已有音位可以修改或清除
4. 用顶部工具栏添加和弦、歌词、演奏记号，或开启选择模式批量编辑
5. 写完可以进入预览查看效果；建议定期导出 JSON 备份

### 常用快捷键

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl / Cmd + Z` | 撤回 |
| `Ctrl / Cmd + Shift + Z` | 重做 |
| `Ctrl / Cmd + C` | 复制选中的音符 |
| `Ctrl / Cmd + V` | 粘贴 |
| `Esc` | 退出选择模式 |

## 数据与隐私

- 所有谱本只保存在当前浏览器的本地数据库（IndexedDB），不会上传服务器
- 清除浏览器数据、使用无痕模式或更换设备/浏览器，都会导致看不到原来的谱本
- 建议定期用「导出」生成 JSON 或 ZIP 备份；换设备时用「导入」恢复
- 图片页只保存图片的 http(s) 地址，不保存图片文件本身

## 常见问题

**谱本会丢吗？**
数据存在浏览器本地。清理浏览器缓存/站点数据、无痕窗口关闭或重装浏览器都可能丢失，重要谱子请导出备份。

**支持手机吗？**
可以打开和查看，简单编辑也没问题；制谱建议用电脑，点击更精准。

**能打印或分享吗？**
预览模式适合打印；分享谱子可以通过导出 JSON 文件发给对方，再导入即可。

**图片页为什么只能填链接？**
当前版本用图片 URL 引用，避免把大图片塞进本地数据；把图片放到可访问的 http(s) 地址即可。

## 开发者

技术栈：React + TypeScript + Vite，数据层使用 Dexie（IndexedDB）。

```bash
npm install
npm run dev      # 本地开发
npm run build    # 构建静态站点
```

自动构建部署（CI）流程见 [deploy.md](deploy.md)，发布脚本与 nginx 配置在 `deploy/` 目录。
